# SargaPulcsis – Factorio mods

Static site listing my mods from the [Factorio Mod Portal](https://mods.factorio.com/user/SargaPulcsis).
Made with the help of AI (Claude by Anthropic).

- `index.html`: looping belt of mods plus a full list
- `mod.html?m=<mod-name>`: details, description, gallery, changelog, versions
- `data/mods.js`: generated by `scripts/fetch_mods.py` (the portal API has no CORS, so the browser can't fetch it directly; a script file also works when the pages are opened from disk)

## Közzététel GitHub Pages-en (egyszer kell megcsinálni)

1. **GitHub fiók**: ha még nincs, regisztrálj a github.com-on. A felhasználóneved lesz a cím része.
2. **GitHub Desktop** telepítése: <https://desktop.github.com>, majd jelentkezz be benne a fiókoddal.
3. GitHub Desktopban: **File → Add local repository…** → válaszd ki ezt a `website` mappát.
   Azt írja majd, hogy ez még nem repository → kattints a **create a repository** linkre → **Create repository**.
4. **Publish repository** (felső sáv):
   - Name: `<felhasználónév>.github.io` (pontosan a GitHub felhasználóneved, pl. `SargaPulcsis.github.io`)
   - **vedd ki a pipát** a „Keep this code private” elől (Pages ingyen csak publikus repóval megy)
   - Publish.
5. A github.com-on nyisd meg a repót → **Settings → Pages** → *Build and deployment* → Source: **GitHub Actions**.
6. **Actions** fül → bal oldalt **Deploy site** → **Run workflow** → Run workflow.
   (Az első automatikus futás valószínűleg hibát dobott, mert a Pages még nem volt bekapcsolva. Ez normális.)
7. 1-2 perc múlva zöld pipa → az oldal él: `https://<felhasználónév>.github.io`
   (a címet a Settings → Pages tetején is látod).

Opcionális: a Mod Portalon a modjaid *Source URL* / *Homepage* mezőjébe beírhatod az oldal címét.

## Frissítés

- **Új mod vagy új verzió a portálon:** semmit nem kell csinálni, az oldal 6 óránként magától frissül.
  Ha azonnal kell: Actions → Deploy site → Run workflow.
- **Az oldal kódjának módosítása:** GitHub Desktopban Commit → Push origin, és pár perc múlva élesben van.
- Ha a GitHub mégis leállítaná az időzített futást (60 nap inaktivitás után szokta), e-mailt küld,
  és az Actions fülön egy kattintással újra bekapcsolható. A workflow elvileg magától ébren tartja magát.

## Helyi futtatás

Elég duplán kattintani az `index.html`-re. A friss adatokhoz:

```
python scripts/fetch_mods.py
```
