# SargaPulcsis – Factorio mods

Static site listing my mods from the [Factorio Mod Portal](https://mods.factorio.com/user/SargaPulcsis).
Made with the help of AI (Claude by Anthropic).

- `index.html`: looping belt of mods, a full list, and mods in development
- `mod.html?m=<mod-name>`: details, description, gallery, download history, changelog, versions
- `compat.html`: Factorio versions and dependencies of every mod
- `data/mods.js`: generated by `scripts/fetch_mods.py` (the portal API has no CORS, so the browser can't fetch it directly; a script file also works when the pages are opened from disk)
- `data/history.json`: one download count per mod per day; the workflow commits it back daily
- `data/upcoming.js`: the "In development" list, edited by hand
- Visits are counted with [GoatCounter](https://sargapulcsis.goatcounter.com) (no cookies)
